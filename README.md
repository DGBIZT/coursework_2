
# Курсовой проект №2
## API и библиотека requests с внешним сервисом

1. Описание:
```
 Программа которая получает информацию о вакансиях с платформы hh.ru и сохраняет в файл, позволяет удобно работать,добавлять, удалять, фильтровать 
```
2. Клонируйте репозиторий:
```
https://github.com/DGBIZT/coursework_2.git
```
3. Тестироварие:
```
htmlcov/index.html
```
4. 
###### №1
```
Создан абстрактный класс для работы с API сервиса с вакансиями. Реализован класс, наследующийся от абстрактного класса, для работы с платформой hh.ru.
```
###### №2
```
Создан класс для работы с вакансиями. В этом классе определены атрибуты. Класс поддерживает методы сравнения вакансий между собой по зарплате.
```
###### №3
```
Определен абстрактный класс, который обязывает реализовать методы для добавления вакансий в файл, получения данных из файла по указанным критериям и удаления информации о вакансиях.
```

```
Создана функцию для взаимодействия с пользователем.
```
